# Обновление и откат (Update & Rollback)

## Обновление

Обновление `v1.1.0 → v1.1.1`:

- сохраняет настройки;
- сохраняет Windows Credential Manager entry;
- сохраняет `runs/logs`;
- обновляет приложение;
- обновляет встроенный Exchange MCP;
- применяет миграцию config;
- создаёт резервную копию;
- выполняет post-update smoke;
- при ошибке предлагает откат.

Встроенный MCP обновляется **только вместе с релизом** Calendar Event Planner.
Каждая версия приложения ссылается на конкретную версию MCP — произвольный
`latest` не используется.

## Резервная копия

Перед обновлением сохраняется в `%LOCALAPPDATA%\CalendarEventPlanner\backups\`:

- предыдущая версия приложения;
- предыдущий MCP bundle;
- предыдущий `settings.json`;
- `component-manifest.json`.

## Откат

Кнопка «Вернуться к предыдущей версии» откатывает приложение и MCP, но **не
откатывает** пользовательские данные (настройки, логи, runs, credentials).
