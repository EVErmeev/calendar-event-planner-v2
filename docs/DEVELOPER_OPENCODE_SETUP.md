# OpenCode setup (разработчики)

OpenCode skills и инструменты относятся только к среде разработки и **не**
входят в пользовательский продукт. Пользовательский installer их не
устанавливает.

## Ветки

- `master` — стабильные релизы.
- `feature/v1.1.0-windows-installer` — разработка installer v1.1.0.

## Правила

- Не смешивать release-коммиты с разработкой installer.
- Не изменять tag `v1.0.1` после публикации.
- Не создавать реальных событий в автоматических тестах.

## Полезные навыки (skills)

- `bpmn-diagrams` — схемы процессов.
- `ascii-process-schema` — текстовые диаграммы.
- `audit-1c-project-materials` — desk-аудит материалов.
