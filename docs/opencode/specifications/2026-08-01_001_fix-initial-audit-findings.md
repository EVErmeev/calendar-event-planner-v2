# ТЗ: устранение замечаний первичного аудита

## Статус

`active`

## Основание

`docs/opencode/audits/2026-08-01_08fb92d_initial-functional-audit.md`

## Цель

Довести проект от архитектурного прототипа до работающего end-to-end приложения по этапам 1–6.

## Приоритет выполнения

### P0

1. Реализовать реальный MCP transport и dependency injection.
2. Реализовать фактическую проверку подключений.
3. Подключить этапы 3–6 к GUI.
4. Исправить определение timezone из колонки согласованного времени.
5. Перевести CLI compare/create с fixture-заглушек на application services.
6. Добавить `calendar_planner/cli/__main__.py`.
7. Подключить `EventEditorFrame` к этапу 6.
8. Исправить повторное редактирование полей.
9. Исправить mapping UI-значений в Enum.
10. Реализовать реальную повторную проверку дубля.
11. Заблокировать создание stale/duplicate/invalid draft.
12. Добавить GitHub Actions.

### P1

Выполнить все замечания раздела P1 последнего аудита.

## Обязательная приёмка

OpenCode должен показать:

- commit до и после;
- список изменённых файлов;
- зелёный CI;
- pytest и coverage;
- MCP contract tests;
- end-to-end dry-run;
- артефакты этапов 1–6;
- корректное определение `Asia/Yekaterinburg`;
- фактические результаты сравнения календаря;
- участников отдельно по каждой встрече;
- редактирование длительности, времени, участников и повестки;
- корректный start/end payload;
- подтверждение, что реальные события не создавались.

## Правило закрытия замечания

Для каждого замечания:

1. воспроизвести;
2. добавить падающий тест;
3. исправить первопричину;
4. показать прохождение теста;
5. сослаться на commit и файл;
6. отразить результат в validation report.
