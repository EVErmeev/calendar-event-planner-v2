# Первый запуск (First Run)

Мастер первого запуска открывается автоматически, если
`first_run_completed != true`, либо по команде «Настройки → Повторить
первоначальную настройку».

## Экран 1 — приветствие

Показывает:

- версию приложения;
- версию встроенного Exchange MCP;
- путь установки;
- путь пользовательских данных.

Кнопки: «Начать настройку», «Открыть техническую информацию», «Отмена».

## Экран 2 — корпоративная почта и EWS

- EWS endpoint (по умолчанию `https://mail.1cbit.ru/EWS/Exchange.asmx`, можно
  изменить);
- логин;
- пароль;
- чекбокс «Запомнить пароль на этом компьютере».

После ввода проверяется:

- NTLM authentication;
- read-only EWS ResolveNames;
- read-after-write в Windows Credential Manager.

Пароль не выводится на экран.

## Экран 3 — тестовый поиск сотрудника

Введите ФИО (например, «Ермеев Егор»). Показываются ФИО, email, статус
разрешения и число найденных вариантов.

## Экран 4 — Exchange MCP

Приложение находит встроенный MCP относительно каталога установки. Проверяются:
процесс, инициализация, `tools/list`, наличие `find_events` и `create_event`,
read-only чтение календаря, версия MCP и встроенное исправление приглашений.

`create_event` **не вызывается** — проверяется только его наличие.

## Экран 5 — часовой пояс и параметры

- основной timezone;
- timezone событий без timezone;
- единица числовой длительности;
- default source schema profile.

Для текущего пользователя по умолчанию `Asia/Yekaterinburg`. Значение
сохраняется при обновлении.

## Экран 6 — итог

Таблица: Application runtime, Credential Manager, EWS authentication,
EWS ResolveNames, Exchange MCP, find_events, create_event tool, Logs dir,
User config.

Кнопки: «Начать работу», «Повторить неуспешные проверки»,
«Скопировать диагностику», «Открыть логи».

`first_run_completed=true` выставляется только если обязательные компоненты
готовы, либо пользователь явно выбрал продолжение с предупреждением.
