# Удаление (Uninstall)

Удаление через «Меню Пуск → Удалить Calendar Event Planner».

## Варианты удаления

Installer спрашивает:

- **Удалить только программу** — удаляет файлы приложения из
  `%LOCALAPPDATA%\Programs\CalendarEventPlanner\`.
- **Удалить программу и пользовательские данные** — дополнительно удаляет
  `%LOCALAPPDATA%\CalendarEventPlanner\` (logs, runs, diagnostics, настройки).

## Credential Manager

Пароль из Windows Credential Manager удаляется **только при явном согласии
пользователя**. Без согласия запись сохраняется — чтобы не блокировать доступ
другим приложениям и не удалять данные, которые пользователь не просил
удалять.
